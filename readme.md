# ORCA – Marine Intelligence Assistant 

**AI-Powered Marine and Inland Environmental Intelligence Platform**

## Project Overview

ORCA (Marine EcOsystem Reasoning with Collaborative Agents) is an AI-powered environmental intelligence platform developed to analyze marine and inland environmental conditions.

The application integrates environmental data sources, risk assessment techniques, and Google Gemini AI to retrieve, analyze, and explain environmental information in a user-friendly way.

## Features Implemented

- **Location Search:** Implemented location search to retrieve geographical coordinates using location names.
- **Interactive Map:** Integrated Leaflet.js to allow users to search for and select geographical locations.
- **Marine Analysis:** Integrated Copernicus Marine to retrieve oceanographic data and analyze marine conditions.
- **Inland Analysis:** Integrated Open-Meteo to retrieve weather data and analyze inland environmental conditions.
- **Risk Assessment:** Developed separate risk assessment modules for marine and inland environmental conditions.
- **AI-Powered Explanations:** Integrated Google Gemini to generate explanations based on environmental analysis.
- **AI Question Answering:** Implemented an API that allows users to ask natural-language questions about marine conditions.
- **REST API Development:** Developed backend endpoints using FastAPI to connect the frontend with environmental data services and AI functionality.
